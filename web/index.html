FailFirst

Prove the bug.
Then fix it.

Give FailFirst a GitHub issue. It writes a test that fails because of the bug, then tries several fixes in parallel sandboxes and only hands you a patch that makes that test pass without breaking anything else.

No issue? Describe the bug instead

  1. InvestigateNemotron Nano triages; Super reads the code to find the root cause.
  2. ReproduceSuper writes a test. It must fail in the sandbox, for the reported reason.
  3. CheckpointThe failing state is saved as an immutable sandbox image.
  4. BranchUltra plans distinct strategies; each is patched and tested in parallel from the checkpoint.
  5. VerifyA patch wins only if the repro passes and no existing test regresses.
